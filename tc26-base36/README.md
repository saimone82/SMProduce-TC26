# TC26 2.0.49 — real 2.0.36 baseline

Base: `Pallets-Shipping-TC26-2.0.36-CORRETTA-COMPLETA(2).apk`, uploaded by the owner.
SHA-256: `c37446076d1f7d7cbf6fd8c02583d0e02b942eb5424b383a246e56f7ef74168a`.

This build preserves all six original DEX files and assets byte-for-byte. It adds
one Java-compiled activity extending the original `TC26Activity`. Compile-only
ABI stubs are never packaged. No files from the older 2.0.5/48 MainActivity are used.

- Original 36 network readiness, device metadata, Scanner, Complete rules,
  case mismatch protection, shipment popup/voice and BOL handling are retained.
- Original 9-second connect, 20-second normal and 90-second shipment/BOL timeouts.
- No `ping` gate and no acceptance of HTTP errors as successful operations.
- Network checks at entry points and immediately before sending requests.
- Offline queue replay remains disabled. No offline counters are fabricated.
- HTTP status/invalid JSON/ambiguous network outcomes shown explicitly.
- Modify: lookup/add/remove, status choices, optional label with server printers,
  remembered printer, separately protected deletion. Uses existing Modify API.
- Complete saves still use the original 36 Complete interceptor.

The debug signing key is generated by the build; no original signing key is
available. A distinct package avoids replacing/uninstalling 36 or deleting its
local data. This build does not fix a server returning HTTP 500: it reports the
actual failure instead of mislabelling it as lack of network.

Verification checks original bytecode preservation, package/version/launcher,
signature, ZIP integrity, app ABI references and offline guard entry points.
Physical TC26 and production database mutations are not tested by CI.
